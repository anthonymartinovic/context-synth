# Musical Constraints

## Tempo

Target tempo: 142 BPM

## Key and Tonality

* Prefer minor keys
* Overall style should align with dark electronic / techno-inspired music

## Structure

* Keep the arrangement structured and consistent, with the melodic layer providing contrast
* Core sections should feel dense and energetic; transitional sections should feel lighter and more restrained

## Duration

Target 30 seconds for the generated output. This is a proof-of-concept demonstration, not a full production.

## Technical

Output format: WAV. Sample rate: 32kHz (MusicGen default). Mono or stereo accepted. No post-processing or mastering required — raw model output is sufficient for validation.
