# Musical Constraints

## Tempo

Target tempo: 142 BPM

## Key and Tonality

* Industrial / Noise / Techno

## Structure

* Keep arrangement rigid, except for melody (when it is introduced) - that should contrast well.
* Core sections should feel dense; Non-core ominous but less chaotic

## Duration

Target 30 seconds for the generated output. This is a proof-of-concept demonstration, not a full production.

## Technical

Output format: WAV. Sample rate: 32kHz (MusicGen default). Mono or stereo accepted. No post-processing or mastering required — raw model output is sufficient for validation.
