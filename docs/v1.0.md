# Context Synth v1.0

## Goal

Stable, production-ready release. The pipeline is proven, the schema is stable, and the tool is ready for broad adoption.

## What v1 Delivers

### Stable Artifact Schema

The `context.md` format and metadata schemas are frozen. Third-party tools can reliably produce and consume context artifacts. Breaking changes require a major version bump.

### Full Five-Stage Pipeline

Snap → Extract → Rank → Assemble → Verify, with multi-model support and cross-model verification.

### Paragraph-Level Extraction

Earlier versions extract at the file level. v1 supports paragraph-level granularity -- the extraction stage targets specific paragraphs within files for finer-grained results and more precise source references.

### Additional CLI Commands

- `cs validate` -- verify an existing `context.md` against its sources (confirm hashes match, extractions are still faithful)
- `cs diff` -- compare two context artifacts and show what changed

### CI Integration

- `cs validate` returns exit code 0/1 for CI pipelines
- GitHub Action for automated context regeneration on doc changes

### Documentation

- Comprehensive README with quickstart
- Example projects with sample source docs and generated artifacts
- Contributing guide for provider implementations

## What's After v1

- MCP client for pulling context from external sources (Jira, Confluence, Notion, etc.)
- Git-based signal extraction
- Multi-repo support
- Context graphs
- Organization-wide context

## Success Criteria

1. Full pipeline runs reliably with multi-model support.
2. Artifact schema is stable and documented for third-party tooling.
3. `cs validate` detects stale artifacts in CI.
4. At least one real project uses Context Synth in its daily workflow and finds it valuable.
